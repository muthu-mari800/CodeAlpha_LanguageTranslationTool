# Language Translation Tool
### CodeAlpha AI Internship — Task 1

A web-based language translation tool built with HTML, CSS, and JavaScript.

## Features
- 50+ languages supported
- Auto language detection
- Copy translated text
- Translation history
- Mobile responsive

## Tech Used
- MyMemory Translation API (Free)
- Vanilla HTML/CSS/JS

## How to Run
Just open `language_translation_tool.html` in any browser!
